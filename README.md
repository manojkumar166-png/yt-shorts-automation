🎬 Automated YouTube Shorts Generator (100% Free)
This is a fully automated, completely free pipeline that generates professional, cinematic YouTube Shorts. It reads your scripts, generates realistic voiceovers, fetches HD images, and renders a dynamic, highly-edited video—all running automatically on GitHub Actions.

📂 Project Structure & File Details
Here is exactly what every file in this repository does, and how you can customize it.

1. main.py (The Conductor)
What it does: This is the master script. It manages the daily queue using state.json, reads your script_bank.json, triggers the voice and image generation, and finally calls the video renderer.

How to change:

PER_DAY: Look for PER_DAY = 1. Change it to 5 to generate 5 videos a day.

MAX_FAILS: Look for MAX_FAILS = 3. If a script fails (e.g., Pixabay API is down), it will retry it 3 times before skipping it to the next one.

2. script_bank.json (The Content)
What it does: This is your database of scripts. The pipeline reads from this list, ensuring it never repeats a topic.

How to change: You can add as many scripts as you want. See the "How to Format Scripts" section below for the exact required structure.

3. state.json (The Tracker)
What it does: This file is automatically created. It tracks which scripts have been used and on what date. This prevents the bot from generating the same video twice.

How to change: Do not edit this file manually. If you want to reset the queue and start from the very first script again, simply delete state.json and the script will recreate it.

4. fetch_background.py (The Image Fetcher)
What it does: Connects to the Pixabay API to download 4 unique, vertical (9:16) HD images for each video based on the search queries in your script.

How to change:

per_page: Currently set to 15. Increase this if you want the bot to search deeper for images.

safesearch: Currently set to "true". Set to "false" if you want to allow all search results.

5. audio.py (The Voiceover)
What it does: Uses Microsoft Edge-TTS to generate a realistic voiceover for the Hook and 3 Facts.

How to change:

Voice: Look for "en-US-ChristopherNeural". You can change this to:

"en-US-AriaNeural" (US Female)

"en-GB-RyanNeural" (UK Male)

"en-AU-NatashaNeural" (Australian Female)

Speed: Look for rate="+10%". Change to "+20%" for faster speech, or "-10%" for slower.

6. CreateVideo.py (The Editor)
What it does: The visual engine. It uses moviepy to build the final MP4. It adds a cinematic zoom, color grading (contrast/saturation), camera shake, smooth crossfades, and word-by-word synced white subtitles (using AI Whisper).

How to change:

Text Size: Look for _safe_textclip(word_text, 115, ...). Change 115 to make it larger or smaller.

Text Position: Look for .set_position(("center", 1450)). Change 1450 to move the text up (e.g., 1200) or down (e.g., 1600).

Colors: Look for colorx(clip, 1.2) and lum_contrast(clip, contrast=0.2). Change 1.2 and 0.2 to make it more or less vibrant.

Camera Shake: Look for random.randint(-8, 8). Change 8 to a higher number (like 15) for a more violent shake, or 0 to turn it off.

7. .github/workflows/generate.yml (The Cloud Runner)
What it does: Tells GitHub Actions to wake up every day at 3:30 AM, install the required software (ImageMagick, FFmpeg, Python), run the pipeline, and save the videos as a .zip file for you to download.

📝 How to Format script_bank.json
To ensure your videos have perfect, relevant images, you must follow this exact format.

The Golden Rule for image_queries:
Pixabay is a literal search engine. The image_queries must be 1 or 2 simple words that describe the visual. If you write a long sentence, Pixabay will return 0 results and the video will fall back to a dark gradient.

✅ Good Example:
json
[
  {
    "topic": "the deep ocean",
    "hook": "We know more about the surface of Mars than our own oceans.",
    "facts": [
      "The ocean is 95% unexplored.",
      "The deepest part is the Mariana Trench.",
      "Some deep-sea creatures can live for hundreds of years."
    ],
    "image_queries": ["deep ocean", "underwater", "jellyfish", "ocean waves"]
  }
]
❌ Bad Example (Will fail to find images):
json
[
  {
    "topic": "the deep ocean",
    "hook": "We know more about the surface of Mars than our own oceans.",
    "facts": [
      "The ocean is 95% unexplored.",
      "The deepest part is the Mariana Trench.",
      "Some deep-sea creatures can live for hundreds of years."
    ],
    "image_queries": ["A dark and scary deep ocean with glowing creatures", "The deepest part of the ocean floor", "Huge creatures swimming in the dark"]
  }
]
(Pro Tip: You can use ChatGPT to generate 100+ scripts in this format using this prompt: "Generate a JSON array of scripts. Each must have a topic, hook, 3 facts, and exactly 4 image_queries. The image_queries MUST be 1-2 words max for a stock photo search.")

🚀 How to Run Locally (On Your PC)
Install Dependencies:

bash
pip install -r requirements.txt
(Note: You must have ImageMagick and FFmpeg installed on your PC for MoviePy to work).

Set up API Keys:
Create a .env file in the root folder and add your Pixabay API key:

env
PIXABAY_API_KEY=your_pixabay_key_here
Generate Videos:

bash
python main.py
(The videos will be saved in the output/ folder).

☁️ How to Run on GitHub Actions (Cloud Automation)
Push this code to a GitHub repository.

Go to your repository Settings -> Secrets and variables -> Actions.

Add a new repository secret:

Name: PIXABAY_API_KEY

Value: Your actual Pixabay API key.

Go to the Actions tab, select daily-shorts, and click Run workflow.

Wait 5–10 minutes. GitHub will automatically generate the videos, zip them, and save them in the Artifacts section at the bottom of the page for you to download!
